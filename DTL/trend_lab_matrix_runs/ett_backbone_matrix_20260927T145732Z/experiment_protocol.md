# ETTh 第二轮：逐方法方向准确率与 MSE 联合筛选

2026-09-27，依据用户追加要求，在第二轮结果产生前固定此协议。目标是决定哪些已有 idea 值得继续验证，不是搜索测试集上的最优配置。

## 1. 先澄清已有实验

首轮只有 `linear` 一个基础预测骨干：展平 96×7 历史，经线性层输出 24×7 偏移，再加最后观测值。方向头和残差模块是额外 MLP。首轮没有运行 DLinear、iTransformer、TimeMixer 或预训练时序基础模型。

11 种方法是 11 行对照结果：`base`、`difference`、`direction_head`、`projection`、`projection_single`、`residual`、`residual_direction`、`last_value`、`last_slope`、`majority`、`last_direction`。其中只需训练 5 个网络；两种投影共用方向头，后四项为简单规则。它们不是 11 个创新模型。

首轮“平均方向准确率”始终固定某一种方法，再在样本、预测步、变量、预先指定的尺度及训练随机种子上汇总；没有在不同方法之间平均。第二轮将保留每个尺度、每个种子和每种方法的结果，避免只看总均值。

## 2. 用户关心的联合目标

- 每种最终路径相对相同数据、骨干、seed 的 `base` 比较。
- 分别列出未加死区的一阶 sign accuracy，以及带训练阈值的三分类方向 accuracy（k=1/2/4/8 各自列出，另保留尺度均值）。前者比较相邻预测点涨跌符号，第一步锚定最后历史点，零差分作为 sign=0；后者把小于训练阈值的变化单列 flat。
- 两类方向定义分别判断，不能在见到结果后用表现好的定义替换另一个；给用户的结论必须注明适用的定义。
- 同时报告标准化 MSE、相对同一 base 的 MSE 变化，以及原始单位 MSE 作为补充。各变量量纲不同，原始单位 MSE 可能由大数值变量主导。
- **严格联合获益**：方向 accuracy 增加且标准化 MSE 不增加（仅容忍 1e-8 数值误差）。记录每个 seed 是否满足、每个设置多少 seed 满足，以及均值是否同时满足。+1% 不属于“不增加”；零强度得到与 base 相同的路径也不属于方向增益。
- `direction_head`、`majority`、`last_direction` 的独立分类结果与最终路径分开。方向头预测类别更准但路径保持 base 时，不能算用户要求的联合改进。
- 方法按每个数据×骨干设置分别判断，不把不同方法或跨数据集的准确率混在一起。可用“满足条件的设置数/种子数”概括稳定性，必须同时列出失败设置。

## 3. 固定的补实验矩阵

- ETTh1/ETTh2 × joint linear / 小型 MLP / DLinear × seeds [0,1,2]。
- DLinear 依据本地 Time-Series-Library 参考实现，moving average=25，individual=False，共享 seasonal/trend 线性层；保留原参考模型的绝对值预测语义。加入与参考实现的参数/前向一致性检查，不将自定义 anchored linear 叫做 DLinear。
- 其余沿用首轮：七变量、L=96、H=24、尺度 [1,2,4,8]、60/15/10/15 四段时间划分、stride=4/24、40 epochs、patience=8、batch=64、lr=0.001。
- 每个设置运行原 11 项，以及 `event` / `event_nohazard` 两个既有实现，用于补齐 H3 转折状态递推及其消融。共 13 行结果，仍不等于 13 个创新。
- 不修改方向损失权重、投影 alpha 网格或已有选择规则来追逐测试表现。原选择规则允许验证 MSE 增加 1%；本轮报告按上述更严格的实际结果要求另行判断。
- 转折模块除了相对 base，还须与无 hazard 积分头及普通残差头比较；报告参数量、事件 F1、转折邻域方向错误率。不能将额外参数或额外监督带来的收益直接归因于事件结构。

### 补充归因控制（仅原 joint linear，不重新训练）

在 ETTh1/ETTh2 原 3 个种子的 checkpoint 上增加两项推理控制：`prior_projection` 只用训练标签统计各尺度/预测步/变量的类别概率；`flat_projection` 将所有位置的 flat 概率设为 1，检验平滑/死区收缩能否解释改善。两者都用原软投影算子、相同六点 alpha 网格及原验证选择规则，独立选 alpha 后才评价测试段。

这两项是归因对照，不是新的创新候选。不会打乱不同时间窗口的输入或概率来混入未来信息，也不依据测试分数改控制规则。最终同样分别报告原始 sign 和三分类方向指标与严格 MSE 联合条件，以区分“有些后处理有益”和“学到的方向概率贡献了额外价值”。

## 4. 证据等级

优先继续验证的候选，应在不同数据和不同骨干上重复出现方向与 MSE 的共同改善，并且效果不能完全由更简单对照解释。仅某个设置有效的候选列为条件性保留，明确失败设置。反复损害 MSE、方向无收益或结构消融不支持的现有实现降低优先级；未实现、未测试的候选标记证据不足，不宣称被否证。

配对时间块 bootstrap 从每个预测窗口差值出发，先在已训练种子间取平均，再按 8 个连续窗口重采样 2,000 次。区间条件于当前数据与这些模型，另报种子差异；跨方法筛选没有多重检验校正，不用它宣称正式统计发现。

本轮沿用已检查过的 ETTh 时间段，属于探索性骨干复验，不能冒充全新的独立留出集。通过筛选的候选还需新的时间段、其他数据域、预测长度和正式基线实验；这不会妨碍用本轮证据合理决定下一步资源投入。
