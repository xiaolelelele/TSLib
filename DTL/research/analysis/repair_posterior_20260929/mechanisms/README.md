# Post-hoc descriptive mechanism analysis

No method selection, retraining, or test tuning. Each method is the frozen validation-selected path. Channel/horizon counts average seeds on shared test windows and are not significance tests. Fix/harm percentages use all forecast points as denominator. Candidate class utilities use the learned marginal probabilities, so their gap to realized accuracy diagnoses score quality, not a bound on true accuracy. The marginal-mode utility bound is only for the learned additive score; it is not an empirical accuracy ceiling. This script does not estimate MSE risk guarantees.

Time blocks are four fixed consecutive groups from np.array_split over test-window indices, not blocks selected after inspecting their gains. per_time_block.csv records each seed and method, window count, global origin endpoints, and inclusive forecast-target range. Its accuracy and MSE average all window/horizon/channel points inside that block. MSE is in training-standardized units. Block counts can differ by one window: reconstruct overall results with window-count weights rather than an unweighted block average. Target ranges can overlap if the evaluation stride is shorter than the forecast horizon.

time_block_summary.csv averages seeds within the same block. mean_seed_mse_ratio averages defined per-seed ratios; ratio_of_seed_mean_mse divides the seed-mean method MSE by the seed-mean base MSE. A zero base MSE gives an undefined ratio, recorded as an empty CSV cell; mse_ratio_defined_seeds reports how many seed ratios were available. Four blocks and their shared-window seed repetitions are descriptive strata, not independent experimental replicates or significance tests. These summaries do not change validation selections, establish the cause of validation/test differences, or attribute failure to origin phase.
