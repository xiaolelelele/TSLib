# 本轮结果的机制诊断，非预注册主结果

主矩阵执行中、已看到部分主结果之后写入；下面控制的结果尚未计算。本文件承认这些是 post hoc 诊断，不用它们选择主方法、替换主结果或声称完成公平调参比较。

在所有数据/年份/骨干/seed 上一致评价：

1. 对 base 施加由变量意义固定的范围：SMARD 八种实际负荷/发电非负；USCRN 太阳辐射非负，湿度在 [0,100]；气温不裁剪。使用与标签相同的标准化 float32 边界，报告真值是否违背范围。不增加从测试值拟合的上下限，不用神经网络。
2. 同一个 raw 凸校正器，固定 alpha=10、原 margin/cap/tol，不搜索 alpha；输入分别为训练集按通道的 raw 类别频率、始终 zero 的 one-hot、历史最后一次变化的 one-hot。前三者无需训练方向头，但相较主选择的预算不同，只作固定控制。
3. `confidence_only_flat` 保留学习后验的逐步 top-two gap，固定最高类别为 zero：q(zero)=(1+2gap)/3，其余各 (1-gap)/3。这会保留方向头置信度，但移除它的类别内容；不能标为完全无方向头。

分别报告整体 raw、仅真值非零的 raw、真值为零的 raw、MSE、改对/改错；另外报告分类头 argmax 准确率与同一数值路径方向之间的差距。各对照保留预测路径及求解器诊断。未调参的控制胜出足以指出更简单解释；控制未胜出不能证明主方法的必要性或新颖性。

第二阶段（已看到第一阶段范围控制结果后）：气象 base 的简单范围控制在 raw 上优于主校正。因此对已锁定的 `raw_selected` 和 `paired_gate` 施加完全相同的固定范围，比较它们对已裁剪 base 的剩余增量。这里不重选 alpha、模型或门控阈值，是进一步 post hoc 诊断，须重新预先固定后在新验证数据上复验。范围违背情况直接检查原 CSV 标签，避免标准化 float32 的逆变换误差把真实零值误报为负值。

门控必要性比较必须用同一个 alpha=1 候选的 always-apply 与 gated 版本；不能把 alpha=1 的 gate 与全局选择出的 alpha=10 的收益差直接解释为门控失败。
